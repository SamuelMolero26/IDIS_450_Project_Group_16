2. SHORT DATASET DESCRIPTION + DATA PREPROCESSING
================================================================================

2.1 Dataset Overview

The US Regional Sales dataset contains 7,991 transaction records from 2017-2018 across four sales channels (In-Store, Online, Distributor, Wholesale). Original features include:

- Categorical: Sales Channel, WarehouseCode, CurrencyCode, OrderNumber
- Numerical: Order Quantity, Discount Applied, Unit Cost, Unit Price
- Temporal: ProcuredDate, OrderDate, ShipDate, DeliveryDate
- Identifiers: _SalesTeamID, _CustomerID, _StoreID, _ProductID

Target Variable: Total_Revenue (continuous, range: $100-$43,000, mean: $15,000)

Dataset Characteristics:
- Size: 7,991 rows × 16 columns (original)
- Missing Values: 0.01% (8 records)
- Data Quality: High (no duplicates, logical date sequences)
- Business Context: Multi-channel sales with varying pricing strategies

2.2 Data Preprocessing Pipeline

The preprocessing pipeline consists of 6 sequential stages, implemented in src/data_preprocessing.py:

Stage 1: Data Loading & Exploration
- CSV import with date parsing (DD-MM-YYYY format)
- Initial quality assessment (shape, dtypes, missing values)
- Summary statistics generation

Stage 2: Data Quality Assurance
- Missing value imputation (median for numerical, mode for categorical)
- Date logic validation (ProcuredDate ≤ OrderDate ≤ ShipDate ≤ DeliveryDate)
- Value range checks (non-negative costs/prices, discount ∈ [0,1])

Stage 3: Feature Engineering
- Temporal Features: Procurement_to_Order_Days, Order_to_Ship_Days, Ship_to_Delivery_Days, Total_Lead_Time
- Financial Features: Profit_Margin = ((Unit Price × (1-Discount)) - Unit Cost) / Unit Cost
- Total_Revenue = Order Quantity × Unit Price × (1-Discount)
- Interaction Features: Price_Quantity_Interaction, Discount_Price_Interaction, etc. (7 features)

Stage 4: Outlier Detection & Treatment
- Univariate: Z-score (>4σ) and IQR (3×IQR) methods
- Multivariate: Isolation Forest (contamination=0.05), Local Outlier Factor
- Contextual: Channel-specific outlier analysis
- Result: 4.3% outliers removed, 99.45% data retention

Stage 5: Standardization & Encoding
- Numerical Scaling: RobustScaler (median-based, outlier-resistant)
- Categorical Encoding: OneHotEncoder (drop='first' to avoid multicollinearity)
- Feature Balance Assessment: Skewness analysis for transformation needs

Stage 6: Exploratory Data Analysis
- Correlation Analysis: Pearson correlation matrix
- Distribution Analysis: Skewness validation
- Relationship Visualization: Scatter plots and heatmaps
