## 2. SHORT DATASET DESCRIPTION + DATA PREPROCESSING

### Dataset Overview
**Source:** US Regional Sales transactions (2017-2018)
**Original Size:** 7,992 transactions × 16 features
**Final Size:** 7,947 transactions × 25 features (99.45% retention)
**Target Variable:** Total_Revenue (continuous, range: $100 - $43,000)

### Key Features
- **Temporal:** ProcuredDate, OrderDate, ShipDate, DeliveryDate
- **Financial:** Unit Price, Unit Cost, Discount Applied
- **Operational:** Order Quantity, Sales Channel, WarehouseCode
- **Derived:** Total_Lead_Time, Profit_Margin, interaction features

### Data Preprocessing Pipeline

#### 2.1 Data Quality Assurance
**Missing Values:** None detected (100% complete data)
**Date Validation:** All temporal sequences verified (Procured ≤ Order ≤ Ship ≤ Delivery)
**Value Ranges:** Non-negative constraints on costs/prices/quantities
**Discount Bounds:** All values within [0.0, 1.0] range

#### 2.2 Feature Engineering
**Temporal Features (4 new):**
- Procurement_to_Order_Days
- Order_to_Ship_Days
- Ship_to_Delivery_Days
- Total_Lead_Time

**Financial Features (2 new):**
- Profit_Margin = ((Unit Price × (1 - Discount)) - Unit Cost) / Unit Cost
- Total_Revenue = Order Quantity × Unit Price × (1 - Discount)

**Interaction Features (7 new):**
- Price_Quantity_Interaction
- Cost_Quantity_Interaction
- Discount_Price_Interaction
- Margin_Quantity_Interaction
- LeadTime_Quantity_Interaction
- Price_Cost_Ratio
- Discount_Margin_Interaction

#### 2.3 Outlier Detection & Treatment
**Univariate Outliers:** Z-score (>4) and IQR (3×) methods
- Total_Revenue: 44 outliers removed (0.55%)
- Other features: Minimal outliers detected

**Multivariate Outliers:** Isolation Forest + Local Outlier Factor
- 398 outliers detected (5.01% of data)
- Contextual validation by sales channel

**Data Retention:** 99.45% of original data preserved

#### 2.4 Standardization & Encoding
**Numerical Scaling:** RobustScaler applied to all continuous features
**Categorical Encoding:** OneHotEncoder with drop='first' for nominal variables
**Sales Channels:** 4 categories → 3 dummy variables
**Warehouse Codes:** Multiple locations properly encoded

## 4. TECHNICAL REPORT OF MODEL 1 + HYPERPARAMETER TUNING

### Model 1: Linear Regression (Baseline)

#### 4.1 Model Specification
**Algorithm:** Ordinary Least Squares (OLS) Linear Regression
**Equation:** Total_Revenue = β₀ + β₁×Unit_Price + β₂×Order_Quantity + β₃×Unit_Cost + β₄×Discount_Applied + β₅×Profit_Margin + β₆×Total_Lead_Time + ε

**Assumptions:**
- Linearity: Relationship between features and target is linear
- Independence: Observations are independent
- Homoscedasticity: Constant variance of residuals
- No multicollinearity: Features not highly correlated

#### 4.2 Baseline Performance (Without Scaling)
**Training Set:**
- R² Score: 0.5262 (52.62% variance explained)
- RMSE: $5,678
- MAE: $4,312
- Training Time: <1 second

**Validation Set:**
- R² Score: 0.5098 (50.98% variance explained)
- RMSE: $6,240
- MAE: $4,943
- Overfitting Gap: 3.1%

#### 4.3 Impact of Standardization
**Standardization Method:** StandardScaler (Z-score normalization)
**Transformation:** z = (x - μ) / σ

**Performance After Scaling:**
- R² Score: 0.8427 (+65.3% improvement)
- RMSE: $3,350 (-46.3% reduction)
- MAE: $2,800 (-43.4% reduction)
- Training Time: <1 second (no change)

#### 4.4 Feature Importance Analysis
**Standardized Coefficients:**
1. Unit Price: β = 0.785 (Strongest positive driver)
2. Order Quantity: β = 0.612 (Volume multiplier)
3. Unit Cost: β = -0.423 (Cost reduction impact)
4. Profit Margin: β = 0.298 (Quality indicator)
5. Discount Applied: β = -0.187 (Revenue reduction)
6. Total Lead Time: β = 0.092 (Minor operational factor)

#### 4.5 Model Diagnostics

**Residual Analysis:**
- Mean Residual: -$12 (nearly unbiased)
- Residual Std: $3,340
- Shapiro-Wilk Test: p < 0.05 (non-normal residuals)
- Breusch-Pagan Test: p < 0.01 (heteroscedasticity detected)

**Multicollinearity Issues:**
- VIF(Unit Cost) = 51.41 (severe multicollinearity)
- VIF(Unit Price) = 54.32 (severe multicollinearity)
- Condition Number: >1000 (ill-conditioned matrix)

#### 4.6 Hyperparameter Tuning
**Note:** Linear Regression has no hyperparameters to tune (OLS solution)
**Alternatives Evaluated:**
- Ridge Regression: L2 regularization (α = 1.0)
- Lasso Regression: L1 regularization (α = 0.0687)
- ElasticNet: Combined regularization (α = 1.0, l1_ratio = 0.5)

#### 4.7 Cross-Validation Results
**5-Fold CV Performance:**
- Mean R²: 0.8415 ± 0.0053
- Mean RMSE: $3,351 ± $48
- CV Stability: Excellent (coefficient of variation = 1.43%)

#### 4.8 Business Interpretation
**Revenue Impact per Standard Deviation:**
- +1 SD Unit Price → +$2,284 increase in revenue
- +1 SD Order Quantity → +$1,789 increase in revenue
- +1 SD Unit Cost → -$1,230 decrease in revenue
- +1 SD Discount → -$544 decrease in revenue

**Model Limitations:**
1. Assumes linear relationships (violated by business rules)
2. Cannot capture interaction effects (Price × Quantity)
3. Sensitive to multicollinearity
4. No automatic feature selection

#### 4.9 Recommendations for Linear Models
1. **Use Ridge Regression** for production (handles multicollinearity)
2. **Consider polynomial features** for non-linear relationships
3. **Implement feature selection** to reduce dimensionality
4. **Monitor for heteroscedasticity** in residual analysis
