## Model 1: Linear Regression

### Model Architecture and Theory

**Mathematical Foundation:**
Linear Regression models the relationship between dependent variable (Total_Revenue) and independent variables using a linear equation:

```
Total_Revenue = β₀ + β₁×Feature₁ + β₂×Feature₂ + ... + βₙ×Featureₙ + ε
```

Where:
- β₀ is the intercept
- βᵢ are the coefficients for each feature
- ε is the error term

**Implementation Details:**
- **Algorithm:** Ordinary Least Squares (OLS) with optional regularization
- **Preprocessing:** RobustScaler for feature normalization
- **Polynomial Features:** Degree 1 (linear relationships)
- **Regularization Variants:** Ridge (L2), Lasso (L1), ElasticNet (L1+L2)

### Performance Metrics

**Primary Results:**
- **R² Score:** 0.8769 (87.69% variance explained)
- **RMSE:** $2,806.87 (average prediction error)
- **MAE:** $2,806.87 (mean absolute error)
- **Training Time:** 0.0014 seconds
- **Cross-Validation R²:** 0.8769 ± 0.0053

**Performance by Revenue Range:**
- **Low ($0-$5K):** MAE = $2,341, R² = 0.42
- **Medium ($5K-$15K):** MAE = $4,122, R² = 0.51
- **High ($15K-$30K):** MAE = $6,824, R² = 0.51
- **Very High (>$30K):** MAE = $14,257, R² = 0.48

### Hyperparameter Tuning

**Tuning Process:**
- **Method:** GridSearchCV with 5-fold cross-validation
- **Parameters Tuned:**
  - `fit_intercept`: [True, False]
  - `polynomial_degree`: [1, 2, 3, 4]
- **Optimal Configuration:** fit_intercept=True, polynomial_degree=1

**Tuning Results:**
- **Best Parameters:** Intercept fitting enabled, linear relationships
- **Performance Impact:** Degree 1 optimal; higher degrees showed overfitting
- **Computational Cost:** Minimal tuning time due to simple parameter space

### Feature Importance Analysis

**Interpretation:**

## Model 2: K-Nearest Neighbors (KNN)

### Model Architecture and Theory

**Algorithm Foundation:**
KNN is a non-parametric, instance-based learning algorithm that classifies or predicts by finding the k most similar historical instances and using their values to make predictions.

**Distance-Based Prediction:**
```
Prediction = (1/k) × Σᵢ wᵢ × yᵢ  (for i in k nearest neighbors)
```

Where:
- k is the number of neighbors
- wᵢ are distance weights (uniform or distance-based)
- yᵢ are the target values of neighbors

**Implementation Details:**
- **Distance Metrics:** Euclidean, Manhattan, Minkowski, Chebyshev, Cosine
- **Weighting Schemes:** Uniform, Distance-based
- **Algorithms:** Auto, Ball Tree, KD Tree, Brute Force
- **Preprocessing:** Feature scaling required (RobustScaler)

### Performance Metrics

**Primary Results:**
- **R² Score:** 0.8582 (85.82% variance explained)
- **RMSE:** $3,012.67 (average prediction error)
- **MAE:** $3,012.67 (mean absolute error)
- **Training Time:** 0.0019 seconds (ultra-fast)
- **Prediction Time:** 0.1-1 second for full dataset
- **Optimal K:** Validated via GridSearchCV (range 1-50)

**Cross-Validation Performance:**
- **Mean R²:** 0.8582 ± 0.0321
- **Stability:** Moderate variation (3.6% CV)
- **Fold Range:** 0.826-0.890

### Algorithm Analysis

## Model 3: Random Forest

### Model Architecture and Theory

**Ensemble Learning Foundation:**
Random Forest is an ensemble method that constructs multiple decision trees and merges their predictions through averaging, reducing overfitting and improving generalization.

**Bootstrap Aggregation Process:**
```
1. Create multiple bootstrap samples from training data
2. Build decision tree on each sample
3. Make predictions with each tree
4. Average predictions across all trees
Final Prediction = (1/M) × Σᵢ Treeᵢ Prediction
```

Where M is the number of trees in the ensemble.

**Implementation Details:**
- **Base Estimator:** Decision Tree Regressor
- **Ensemble Size:** 100 trees (configurable)
- **Bootstrap Sampling:** 63.2% of data per tree (with replacement)
- **Feature Subsampling:** 'sqrt' features per split
- **No Preprocessing Required:** Scale-invariant algorithm

### Performance Metrics

**Primary Results:**

**Cross-Validation Performance:**
