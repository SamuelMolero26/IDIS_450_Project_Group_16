Preprocessing Data Analysis from Output and Visuals

This document analyzes the preprocessing steps applied to the US Regional Sales dataset, based on the output in 'Documentation/output/pre-processing.txt' and referencing visuals from 'visualizations/pre-processing/'. The analysis covers each major preprocessing section, explaining what was done, the rationale, and how visuals support the findings.

1. Initial Data Exploration
The dataset was loaded successfully with 7,991 rows and 16 columns. Data types include objects for categorical fields, datetime64 for dates, and numerical types for quantities, costs, and prices. Summary statistics show means (e.g., Unit Cost: 1431.91, Unit Price: 2284.54), standard deviations (e.g., Unit Cost: 1112.41), and ranges (e.g., Unit Price: 167.5 to 6566). No missing values or duplicates were found, indicating high data quality from the start. This exploration establishes a baseline for understanding distributions and scales. Visuals: Enhanced histograms (e.g., visualizations/pre-processing/enhanced_histogram_unit_price.png, enhanced_histogram_unit_cost.png) illustrate the initial distributions, showing skewness and central tendencies that informed subsequent transformations.

2. Data and Variable Explanation
Variables are categorized as categorical (nominal, e.g., Sales Channel with 4 values), numerical (discrete like Order Quantity, continuous like Unit Price), and temporal (dates for lead time calculations). Derived features include temporal differences (e.g., Total_Lead_Time), financial metrics (Profit_Margin, Total_Revenue), and interactions (7 features like Price_Quantity_Interaction). This engineering expands features from 16 to 29, enabling deeper analysis for sales forecasting and segmentation. Visuals: Enhanced histograms for derived features (e.g., visualizations/pre-processing/enhanced_histogram_total_revenue.png, enhanced_histogram_profit_margin.png) display their distributions, while scatter plots (e.g., visualizations/pre-processing/enhanced_scatter_unit_price_vs_total_revenue.png) reveal relationships captured by interactions.

3. Missing Values Analysis
No missing values were detected across all columns, eliminating the need for imputation. This ensures complete data integrity without introducing biases from filling strategies. Visuals: Skewness validation plots (e.g., visualizations/pre-processing/skewness_validation_unit_price.png) confirm distributions remain unaltered, supporting the absence of missing data handling.

4. Data Consistency Check
Date logic was validated (ProcuredDate ≤ OrderDate ≤ ShipDate ≤ DeliveryDate), non-negative checks for costs/prices/quantities, and discount ranges (0.0-1.0). All checks passed, ensuring logical temporal and numerical consistency. This prevents erroneous lead time calculations. Visuals: Not directly applicable, but enhanced histograms (e.g., visualizations/pre-processing/enhanced_histogram_total_lead_time.png) show valid lead time distributions post-check.

5. Data Type Conversion and Feature Engineering
Derived temporal features (4 new), profit margin, and total revenue were added, increasing columns to 22. This creates actionable metrics for business insights. Visuals: Scatter plots demonstrate derived relationships (e.g., visualizations/pre-processing/enhanced_scatter_total_lead_time_vs_total_revenue.png shows minimal correlation), justifying temporal feature inclusion.

6. Creating Interaction Features
7 interaction features were created (e.g., Price_Quantity_Interaction, Discount_Price_Interaction), expanding to 29 columns. These capture complex patterns like volume-pricing dynamics. Visuals: Enhanced scatter plots (e.g., visualizations/pre-processing/enhanced_scatter_order_quantity_vs_total_revenue.png, enhanced_scatter_discount_applied_vs_profit_margin.png) illustrate the non-linear relationships these features address.

7. Univariate Outlier Detection and Removal
Using Z-score (>4) and IQR (3×IQR), 44 outliers were detected in Total_Revenue (0.55%), with none in other variables. Removal reduced rows to 7,947 (99.45% retention), improving model stability. Thresholds were aggressive to minimize bias. Visuals: Enhanced histogram for Total_Revenue (visualizations/pre-processing/enhanced_histogram_total_revenue.png) shows the cleaned distribution, highlighting outlier removal's effect on skewness.

8. Multivariate Outlier Detection
Isolation Forest detected 398 outliers (5.01%), LOF 50 in sample (5.00%). These identify anomalous combinations not caught univarately. Visuals: Scatter plots (e.g., visualizations/pre-processing/enhanced_scatter_unit_cost_vs_profit_margin.png) may show outlier clusters, supporting multivariate detection's necessity.

9. Contextual Outlier Detection
74 unusually long Procurement_to_Order_Days were flagged, with no others. This channel-specific check preserves business context. Visuals: Enhanced histogram for Total_Lead_Time (visualizations/pre-processing/enhanced_histogram_total_lead_time.png) reflects contextual validation.

10. Dataset Balance Assessment
Sales Channel and WarehouseCode are balanced (no category >70% or <5%). CurrencyCode is imbalanced (100% USD). Numerical skewness: Order Quantity (0.00, normal), Discount Applied (1.96, highly skewed), Unit Cost (1.10), Unit Price (0.86), Profit_Margin (0.53), Total_Revenue (1.47). This informs transformation needs. Visuals: Skewness validation plots (e.g., visualizations/pre-processing/skewness_validation_discount_applied.png, skewness_validation_total_revenue.png) assess normality, guiding preprocessing decisions.

11. Exploratory Data Analysis
Correlation matrix shows strong links: Unit Cost-Unit Price (0.942), Unit Cost-Total_Revenue (0.708), Unit Price-Total_Revenue (0.745), Procurement_to_Order_Days-Total_Lead_Time (0.972). 12. Dropping Columns
Columns dropped: CurrencyCode, _SalesTeamID, _CustomerID, _StoreID, _ProductID (imbalanced/identifiers), reducing to 25 columns. This focuses on predictive features. Visuals: Not directly, but balance assessment visuals support dropping imbalanced CurrencyCode.

13. Finalize Preprocessed Dataset
Final shape: 7,947 rows, 25 columns (14 derived). Scaling and encoding applied (though not detailed in output). Dataset saved for ML. Visuals: All referenced histograms and scatters represent the final preprocessed state, enabling model-ready insights.

Overall, preprocessing transformed raw data into a clean, feature-rich dataset with 99.45% retention, supported by visuals that validate distributions, relationships, and quality improvements.
